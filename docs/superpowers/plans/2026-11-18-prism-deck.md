# PRISM-Rec Explained (3D slide deck) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 65-slide interactive 3D deck in `deck/` that explains each PRISM-Rec concept (theory with live 3D → measured impact → code), with every number and code excerpt loaded from the project.

**Architecture:** One persistent React Three Fiber canvas behind HTML slides. Each concept is a self-contained folder that exports a `TheoryDef` (slides, 3D scene, fallback). The shell discovers folders automatically, flies the camera between stations with GSAP, and renders panels with Motion. Data and code excerpts are generated by a Python script from `results/` and `src/prism/`.

**Tech Stack:** Vite, React 19, TypeScript strict, three, @react-three/fiber 9, @react-three/drei 10, gsap + @gsap/react, motion (`motion/react`), zustand, d3-scale, d3-shape, katex, highlight.js (Python only), @noble/hashes, @fontsource fonts, Vitest + Testing Library (jsdom), Playwright on installed Edge, pytest.

**Spec:** `docs/superpowers/specs/2026-11-18-prism-deck-design.md` (section 7 is the storyboard; read it with this plan).

## Global Constraints

- All deck code lives under `deck/`. Nothing in `src/prism/`, `tests/`, `results/` or `experiments/` is modified. The only new file outside `deck/` is `tests/test_deck_export.py`.
- **No git commits or pushes by any worker.** The owner commits. Steps that would say "commit" are omitted.
- No network at run time: no CDN fonts, no drei `<Text>` (it fetches a font), no drei `<Environment preset>` (it fetches an HDRI), no remote images. Labels in 3D use the kit's `<Label>` (HTML).
- No dataset rows, user or business identifiers, or device-trace content anywhere under `deck/`. Only aggregates from `results/*.json`.
- No number typed into a slide by hand: use `m()`, `raw()` or `fact()` from `src/data`. No conference or journal paper cited; no department framing.
- Every slide has a badge: `measured`, `computed` or `illustration`. Impact slides are `measured` or `computed` and list `sources`.
- A panel holds at most about 130 words. More text means another slide.
- Per-frame values live in refs. No `setState` inside `useFrame`. GSAP owns everything inside the canvas; Motion owns HTML. Kill timelines on unmount (`useGSAP` does this).
- Colour comes only from role tokens (section "Shell interfaces"), never literal hex in a theory folder.
- Reduced motion: scenes must reach the same end state without animation (`useStepTimeline` handles it).
- Performance pass mark on this laptop at 1920×1080: median frame ≤ 16.7 ms, p95 ≤ 25 ms per slide. At most about 2,000 instances per scene; no per-frame allocation.
- Workers building a theory folder write only inside `deck/src/theories/<id>/`, never start a dev server, and never install packages.

## Review Focus

1. A result key renamed or missing after a rerun → the deck must fail loudly at test time, not show `NaN`. (`m()` throws; Task 1 and Task 2 tests.)
2. Reload or deep link on any slide (`#/dp/3`), or a hash that names no slide → lands on that slide, or on slide 1, never a blank page. (Task 2 test.)
3. Pressing Right quickly many times while the camera is still flying → ends on the right slide with the camera at that slide's pose. (Task 2 test on the store; Task 6 end-to-end.)
4. WebGL unavailable or context lost → text, charts and code remain usable with the SVG fallback. (Task 2 test with `webgl=false`; Task 6.)
5. A slider dragged to its extreme (cohort of 0, attacker share 0 or 30%, committee size larger than the cohort, noise 0) → the simulation returns finite values. (Each theory's `sim.test.ts`.)

## Shell interfaces (produced by Tasks 1–3, consumed by every theory)

> **As built.** The working reference for theory builders is `deck/docs/BUILDING_A_THEORY.md`
> and the source of `deck/src/world/kit/` and `deck/src/ui/`. Differences from the block
> below: a fourth badge `"source"` for code slides; `Buttons`, `Readouts`, `Caption`, `Steps`,
> `List` and `Table` were added to the UI; `useOnReset(fn, active)` takes the station's
> `active` flag; `useActiveFrame` and `useDrag` were added to the kit; labels are an HTML
> layer positioned by a projector inside the canvas (drei's `Html` raised React errors);
> a scene fits a box 10 wide, 8 tall and 10 deep rather than a radius of 9; `?solo=1`
> mounts only the current station (used by the smoke script).

```ts
// src/deck/types.ts
export type SlideKind = "theory" | "impact" | "code" | "extra";
export type Badge = "measured" | "computed" | "illustration";
export type Vec3 = [number, number, number];
export interface Pose { position: Vec3; target: Vec3 }        // station-local units
export interface SlideDef {
  id: string;                    // `${theoryId}/${n}`, n from 1
  kind: SlideKind;
  title: string;
  badge: Badge;
  sources?: ResultFile[];        // required on impact slides
  pose: Pose;                    // default { position: [0, 2, 14], target: [0, 0, 0] }
  step: number;                  // scene state passed to Scene
  layout?: "split" | "stage";    // split: panel left, scene right (default). stage: panel left, Stage card over a dimmed scene
  Panel: React.ComponentType;    // text and controls
  Stage?: React.ComponentType;   // charts or code, shown in the right area when layout is "stage"
}
export interface SceneProps { step: number; active: boolean }  // active: this station is the current one
export interface TheoryDef {
  id: string; number: number;    // 0 opening, 1..13 theories, 14 closing
  title: string; short: string;  // short: rail label, at most 14 characters
  slides: SlideDef[];
  Scene: React.ComponentType<SceneProps>;   // rendered inside the canvas at the station origin; keep within radius 9
  Fallback: React.ComponentType;            // SVG schematic, viewBox 0 0 800 600
}
```

Each theory folder has `index.tsx` with `export const theory: TheoryDef`. The registry (`src/deck/registry.ts`) loads `../theories/*/index.tsx` with `import.meta.glob`, skips folders that fail to import (recorded in `window.__deck.failed`), and sorts by `number`.

Theory-local state (slider values shared by Panel and Scene) is a zustand store inside the theory folder, created with `create` from `zustand`, read in the scene through refs or selectors, and reset through `useOnReset`.

World conventions: y is up; a scene fits inside a sphere of radius 9 around the station origin; the default camera is 14 units back and 2 up with a 40° field of view. The shell shifts the view so the origin appears in the middle of the area right of the panel. Lights are provided by the shell (one key, one fill, ambient); scenes add none. Points of light use unlit materials; structures use `meshStandardMaterial`.

### Task 2: Shell

**Produces:** everything in "Shell interfaces" except charts and code view (Task 3), plus:
- `useDeck` store: `{ index, count, go(i), next(), prev(), first(), last(), theme, toggleTheme(), overview, toggleOverview(), resetNonce, reset(), reducedMotion, webgl }`. `go` clamps to `[0, count - 1]`.
- `hash.ts`: `toHash(slideId): string` (`"#/dp/2"`), `fromHash(hash, slides): number` (index, or 0 when unknown).
- `stations.ts`: `stationOrigin(number): Vec3` (stations 70 units apart along a shallow arc), `worldPose(number, pose): Pose`.
- `checkTheory(theory): string[]` — problems found: ids not `${id}/${n}` in order; kinds out of order (for numbers 1–13: one or more `theory`, then one or more `impact`, then one or more `code`, with `extra` allowed anywhere; 0 and 14 are all `extra`); an impact slide without `sources` or with badge `illustration`; `short` longer than 14 characters; a `layout: "stage"` slide without `Stage`.

- Keys: Right / Space / PageDown next; Left / PageUp previous; Home, End; `O` overview; `F` fullscreen; `T` theme; `R` reset. Keys are ignored while an input has focus, except that Right and Left on a slider move the slider.
- Canvas: `dpr={[1, 1.75]}`, `frameloop` "always" on theory and extra slides, "demand" on stage slides (the rig invalidates while flying). Current station ±1 mounted; others unmounted.
- Camera flight: 1.2 s `power3.inOut` between theories, 0.7 s inside one; a new `go` during a flight retargets from the current camera position. Reduced motion: cut.
